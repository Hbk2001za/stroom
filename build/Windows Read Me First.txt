STROOM — WINDOWS INSTALL INSTRUCTIONS
======================================

1. Run "Stroom Setup.exe".

2. WINDOWS SMARTSCREEN WILL BLOCK IT — this app isn't code-signed with
   a paid certificate, so Windows flags it the first time. To proceed:

     - Click "More info"
     - Click "Run anyway"

   You only need to do this once, for the installer itself.

3. Follow the setup wizard (you can choose the install location).

4. THAT'S IT — yt-dlp, ffmpeg, and spotdl are bundled inside the
   installer, so YouTube/MP3/Spotify/Any-Site downloads work
   immediately with no further setup.

   The one exception is "Remove Vocals" (Beta), which needs demucs
   installed separately since it depends on PyTorch (too large to
   bundle). If you want that feature:

     - Install Python from https://www.python.org/downloads/
       (tick "Add python.exe to PATH" during install)
     - Sign out and back in (or restart your PC) so Windows picks up
       the PATH change
     - Open Stroom and click "Update Tools" at the bottom of the app —
       it installs everything needed automatically

5. UPDATES — Stroom checks for new versions on launch and shows a
   banner with a one-click "Download & Install" button when one's
   available.
